# Development

```shell
bundle install
bundle exec rake
```

The first run generates a Spree dummy app in `spec/dummy`, then runs the suite.
If `spec/dummy` was generated by an older Spree, delete it and run again.

CI runs Spree 6.0.0 and the newest 6.x on Ruby 3.3 and 4.0. To test against a
particular Spree:

```shell
SPREE_VERSION=6.0.0 bundle update spree
bundle exec rake
```

Lint with [Standard](https://github.com/standardrb/standard), and scan with
Brakeman:

```shell
bundle exec standardrb        # add --fix to correct what it can
bundle exec brakeman --force --no-pager --quiet --exit-on-warn
```

## Releasing

1. In the pull request, bump `Spree::Shipstation::VERSION` in
   `lib/spree/shipstation/version.rb` and add the release to `CHANGELOG.md`.
2. After it merges, push a `vX.Y.Z` tag on the release commit. The Release
   workflow publishes the gem to RubyGems.

`main` holds the 6.x line. The 5.0.x releases for Spree 5 live on `5-0-stable`.
